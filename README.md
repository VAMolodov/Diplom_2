Автотесты для проверки API Stellar Burgers


Структура проекта
в директории tests расположены файлы с тестами;

файл conftest содержит фикстуры: здесь создаются уникальные пользователи перед каждым требующим того тестом, а после — удаляются из базы;

в gfgrt methods — функции, генерирующие рандомные тестовые данные с помощью библиотеки Faker, метод который создает пользователя и удаляет ;

файл data хранит определены адреса сервиса и его эндпоинтов и предопределенные тестовые данные, передаваемые в запросах;

каталог allure_results хранит JSON-файлы с результатами выполнения тестов для генерации отчета;

в файле requirements.txt перечислены все внешние зависимости исполняемых тестов для удобной установки одной командой;

Реализованные сценарии
Задание проекта не требует полностью покрыть API сервиса тестами. В рамках выполнения работы нужно было проверить исполнение конкретных функциональных требований:

тесты в файле test_create_user проверяют cоздание пользователя:
создать уникального пользователя;
создать пользователя, который уже зарегистрирован;
создать пользователя и не заполнить одно из обязательных полей.

тесты в файле test_creating_order проверяют создание заказа:
с авторизацией;
без авторизации;
с ингредиентами;
без ингредиентов;
с неверным хешем ингредиентов.

тесты в файле test_login_user проверяют логин пользователя:
вход под существующим пользователем;
вход с неверным логином и паролем.

Запуск автотестов
Установка зависимостей

$ pip install -r requirements.txt

Запуск всех тестов одной командой

pytest -v
